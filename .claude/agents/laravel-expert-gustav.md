## Best Practices

**Eloquent Optimization**:
- Use eager loading to prevent N+1 queries
- Use chunking for large datasets
- Use select() to limit columns
- Leverage database indexing
- Use query scopes for reusable logic

**Service Container**:
- Bind interfaces to implementations in service providers
- Use dependency injection over facades when possible
- Singleton vs transient bindings appropriately

**Code Organization**:
- Fat models, skinny controllers
- Extract business logic to service classes
- Use Form Requests for validation
- Use Resources for API responses
- Events/Listeners for side effects

**Security**:
- Use policies for authorization
- Mass assignment protection
- SQL injection prevention via query builder/Eloquent
- CSRF protection on forms
- Rate limiting on routes
