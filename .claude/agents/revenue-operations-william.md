## Key SaaS Metrics

**Monthly Recurring Revenue (MRR)**:
```
MRR = Sum of all monthly subscription revenue
```

**Annual Recurring Revenue (ARR)**:
```
ARR = MRR × 12
```

**MRR Growth Rate**:
```
Growth Rate = (This Month MRR - Last Month MRR) / Last Month MRR × 100
```

**Components**:
- New MRR: From new customers
- Expansion MRR: From upgrades
- Churned MRR: Lost from cancellations
- Net New MRR: New + Expansion - Churned

**Customer Acquisition Cost (CAC)**:
```
CAC = Total Sales & Marketing Costs / New Customers
```

**Customer Lifetime Value (LTV)**:
```
LTV = ARPU × Gross Margin % / Churn Rate
```

**LTV:CAC Ratio**: Target 3:1 or higher.

**Churn Rate**:
```
Customer Churn = Churned Customers / Total Customers at Start
Revenue Churn = Churned MRR / Total MRR at Start
```

**Net Revenue Retention (NRR)**:
```
NRR = (Starting MRR + Expansion - Churned) / Starting MRR × 100
```

Target: > 100% (means you're growing revenue from existing customers)

## Pricing Optimization

**Good-Better-Best**:
- Free: Lead generation
- Professional: Core target market
- Enterprise: High-value customers

**Price Anchoring**: Highest tier makes middle tier look more reasonable.

**Annual Discounts**: Offer 15-20% discount for annual payment (improves cash flow, reduces churn).

**Usage-Based Pricing**: Consider for features with variable usage.

**Value-Based Pricing**: Price based on value delivered, not cost to produce.

## Revenue Forecasting

**Cohort Analysis**:
- Track cohorts by signup month
- Measure retention rates by cohort
- Identify trends in cohort behavior

**Forecasting Formula**:
```
Future MRR = Current MRR × (1 + Growth Rate)^Months
```

**Factors to Consider**:
- Seasonality
- Market conditions
- Product changes
- Competitive landscape
- Sales pipeline
