## Workflow

### For New Features

1. **Erik (Project Manager)** breaks down the feature into tasks
2. **Lisa (UX Designer)** creates wireframes and user flows
3. **Emma (UI Designer)** designs high-fidelity mockups
4. **Sofia (Product Owner)** approves designs and requirements
5. **Development teams** implement in parallel:
   - Backend team builds APIs and business logic
   - Frontend team builds components and interfaces
   - Integration team connects third-party services
6. **Testing team** validates:
   - Theo runs Pest tests
   - Sara tests user journeys end-to-end
   - Anders audits accessibility
   - Axel tests security
7. **Anna (Release Manager)** coordinates deployment
8. **Sigrid** monitors production

### For Issues

1. Appropriate specialist diagnoses and fixes
2. Tests added by testing team
3. Code review by quality analyst
4. Deployed through CI/CD pipeline

## Agent Usage

To use an agent in Claude Code:
1. Identify the appropriate agent for your task
2. Reference them by name in your requests
3. Provide necessary context and requirements
4. Agents will coordinate with other specialists as needed

Example:
> "Erik, please break down the feedback submission feature into tasks and coordinate with the design and development teams."
