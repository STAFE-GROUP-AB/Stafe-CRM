## 🔄 Development Workflow for Stafe CRM

### Phase 1: Planning & Design (UI/UX First!)
1. **Erik** receives feature request and breaks it down
2. **Sofia** writes user stories with acceptance criteria
3. **Lisa** creates wireframes and user flows
4. **Emma** designs high-fidelity mockups (Stafe amber theme)
5. **Marcus** adds interaction specifications
6. **Stakeholder approval** before development starts

### Phase 2: Development (Parallel Teams)
```
Backend Team          Frontend Team         Integration Team
    ↓                      ↓                       ↓
Gustav (Laravel)      Maja (Livewire)       Karl (Twilio, APIs)
Oskar (Database)      Wilma (UI)            Nina (Webhooks)
Viktor (APIs)         Elsa (Alpine.js)
Nils (Queues)         Isabelle (Tailwind)
```

### Phase 3: CRM-Specific Development
- **CRM Data Expert**: Contact/Company/Deal models
- **Sales Pipeline Expert**: Deal stages, forecasting
- **Communication Expert**: Twilio VoIP/SMS/WhatsApp
- **AI/ML Expert**: Lead scoring, deal risk analysis

### Phase 4: Compliance & Security
- **Anders, Petra, Karin**: Accessibility audit
- **Johannes**: AI Act compliance (for AI features)
- **Maria, Linda**: GDPR compliance (customer data)
- **Johan**: Security review
- **Kristina**: Code quality assessment

### Phase 5: Testing (Comprehensive)
1. **Theo**: Pest unit and feature tests
2. **Sara**: E2E user journey tests
3. **Jonas**: Performance and load testing
4. **Axel**: Security penetration testing

### Phase 6: Deployment
1. **Anna**: Coordinates release
2. **David**: Laravel Forge deployment
3. **Emma K.**: CI/CD pipeline execution
4. **Sigrid**: Monitoring and alerting setup

## 💡 CRM-Specific Use Cases

### New CRM Feature Development
> "Erik, we need to add AI-powered deal risk analysis. Please coordinate the teams."

Erik will:
1. Break down the feature
2. Get UX/UI designs from Lisa and Emma
3. Coordinate backend (Gustav for Laravel, Oskar for DB)
4. Coordinate AI team (AI/ML Expert for scoring algorithms)
5. Coordinate frontend (Maja for Livewire dashboard)
6. Ensure compliance (Maria for GDPR on customer data)
7. Get comprehensive testing (Theo, Sara, Jonas)
8. Deploy with Anna

### Twilio Integration Enhancement
> "Karl, we need to add call recording transcription."

Karl will:
1. Work with Nina on webhook handlers
2. Coordinate with Gustav on TwilioService
3. Work with AI/ML Expert on transcription via OpenAI
4. Ensure compliance with Maria (recording consent)
5. Test with Theo

### Dark Mode Implementation
> "Maja, we need dark mode on all remaining views."

Maja will:
1. Review current dark mode patterns in dashboard
2. Coordinate with Isabelle for Tailwind classes
3. Update each Livewire view systematically
4. Ensure consistency with Emma's design standards
5. Test accessibility with Anders

## 🎨 Stafe CRM Design Standards

### Color Palette
- **Background**: Amber-50 (light), Gray-900 (dark)
- **Primary**: Emerald-600 (buttons, links, focus rings)
- **Danger**: Red-600 (delete actions)
- **Secondary**: Stone-600 (secondary text)

### Dark Mode
- All views must support dark mode using `dark:` prefix
- Follow dashboard.blade.php as reference

### Components
- Use Jetstream components (modal, button, input)
- Custom: data-table, filter-bar, status-badge, empty-state
